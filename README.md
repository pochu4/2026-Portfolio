# Johann Chua — Portfolio

Personal portfolio site for Johann Chua, a Marketing & Brand Designer. Built with React, React Router, Tailwind CSS, and Framer Motion.

## Stack

- [React 19](https://react.dev/) + [Vite](https://vite.dev/)
- [React Router](https://reactrouter.com/) for client-side routing and page transitions
- [Tailwind CSS v4](https://tailwindcss.com/)
- [Framer Motion](https://motion.dev/) for scroll/mount-triggered animation
- [Oxlint](https://oxc.rs/) + [Prettier](https://prettier.io/)

## Development

```bash
npm install
npm run dev       # start the dev server
npm run build      # production build
npm run preview    # preview the production build locally
npm run lint        # lint
npm run format       # format with Prettier
```
